# Word 图片批量统一尺寸（VBA）

适用于 Windows 版 Microsoft Word：把整个文档的图片设为统一宽度，或只调整选中的几张／不相邻的特定图片。支持常见的**嵌入型图片**和**浮动型图片**；默认锁定纵横比，避免拉伸变形。

> ⚠️ 请先 **文件 → 另存为** 备份。宏只调整图片尺寸，不会自动识别“公章”“Logo”或“报告截图”；图片含文字时缩小可能影响可读性。无法保证所有组合形状、图表、页眉图片均参与处理。

## 运行前准备

1. 在 Word 中打开需要编辑的文档并保存副本。
2. 按 **Alt + F11** 打开 VBA 编辑器。
3. 选择 **文件 → 导入文件**，导入 [`WordImageSize.bas`](WordImageSize.bas)；也可选择 **插入 → 模块**，粘贴 `.bas` 文件中除 `Attribute VB_Name = ...` 之外的代码。
4. 回到 Word，按 **Alt + F8**，在宏列表选择下方命令，点击 **运行**。如组织策略禁止宏，请遵守管理员的安全设置，不要降低宏安全级别。
5. 若需长期保留宏，可保存到 `.docm` 或 Word 模板；一般 `.docx` 不能保存宏代码，但可以作为运行宏的目标文档。

## 五种操作

| 需求 | 宏名称 | 使用说明 |
| --- | --- | --- |
| 所有图片统一宽度、保持原比例 | `ResizeAllPicturesProportionally` | 无需选择；输入如 `5` cm。 |
| 一次选中连续范围中的多张图片 | `ResizeSelectedPicturesProportionally` | 在 Word 正文中用鼠标选中**包含多张嵌入式图片的文本范围**，或 Ctrl+单击选中多张浮动图片，再运行。 |
| 查看文档图片编号 | `ListPictureIndices` | Alt+F11 → Ctrl+G 查看“立即窗口”中的 `I1`、`F2` 等编号及参考页码。 |
| 不连续的指定图片统一宽度 | `ResizePicturesByIndices` | 输入如 `I1,I4,I7,F2`，然后输入宽度；适合跨页、不相邻的图片。 |
| 所选图片统一指定宽和高 | `ResizeSelectedPicturesExactSize` | 输入如宽 `5` cm、高 `3` cm；**可能改变图片比例**。 |

### 操作示例 A：全文盖章图片宽度统一

如果文档**全部图片均为盖章图片**，运行 `ResizeAllPicturesProportionally`，输入 `4`。如果文档还包含其他截图，**不要运行全选宏**，而应先用 `ListPictureIndices`，再用 `ResizePicturesByIndices` 指定实际盖章编号（例如 `I3,I8,I11`）。

### 操作示例 B：只修改其中三张相隔很远的图片

运行 `ListPictureIndices`，打开 VBA 立即窗口确认各编号及页码；假设目标是 `I2`、`I7` 和 `F3`，运行 `ResizePicturesByIndices` 输入 `I2,I7,F3`，再输入 `5`。程序只修改这三张图片的宽度，其他图片不变。

### 操作示例 C：一段文字中夹着多张嵌入式图片

在 Word 中拖选从第一张图片到最后一张图片的**连续正文范围**；运行 `ResizeSelectedPicturesProportionally`。范围内的其他嵌入图片也会被修改，因此请先检查选择范围。

### 操作示例 D：几张浮动图片

如果图片不是“嵌入型”，可在 Word 中按 Ctrl 逐一单击多张浮动图片并运行所选图片宏。不同 Word 版本、对象布局下，Ctrl 多选可能不成功；此时使用“按编号指定图片”更稳定。

## 两种尺寸规则

**推荐：保持比例，统一宽度**。代码设置 `LockAspectRatio = msoTrue`，统一 `Width = CentimetersToPoints(5)`，高度自动按原始比例变化；适合照片、盖章图、技术插图。

**可选：强制相同宽高**。代码设置 `LockAspectRatio = msoFalse`，同时设 `Width` 与 `Height`，适用于本就等比例的图片，否则会拉伸变形。若要既完全相同宽高又不变形，应先用 Word 的“裁剪 → 纵横比”逐一设置裁剪框，再统一尺寸。

## 常见问题

**为什么某些图片没被修改？** 代码针对普通图片对象：`InlineShapes` 中的图片和 `Shapes` 中的图片。组对象、某些 SmartArt、图表、页眉页脚或文本框内部的图片可能不会被处理；这类对象建议手动调整，或针对其所在 Story/Group 单独扩展宏。

**为什么图片突然到了别的页面？** 图片尺寸改变后，Word 会重新分页。可检查“文字环绕”、对象锚点、段落分页控制和表格行高。

**为什么列表里的页码不一定准确？** `F` 类浮动图片列出的是**锚点所在页**，不是视觉显示位置；图片顺序和编号也可能因增删对象而变化。建议一次性列出、确认、调整；如有增删图片，请重新列出编号。

**需要固定所有图片位置吗？** 这份工具只调整尺寸，不改变图片的锚点、版式或环绕设置。正式盖章文档请复查盖章位置与正文是否重叠。
